One Team Design reference · app shell

App shell

Sidebar 262px · header · content · every authenticated screen

The chrome every signed-in screen sits in, drawn twice: once as an admin sees it, once as a member does. Board sits behind it, because Board carries the busiest header — title block, grouping control, search, and New issue pinned far right. No team switcher and no breadcrumb: there is one team, and the sidebar already says which project you are in.

One difference, and it is a removal: Accounts and Labels are gone, and with them the plus beside Projects — creating a project is admin-only. Everything else is identical. The same five projects, because everyone reads every project; the same New issue button, because Tomáš is a member of this one. Search shows its collapsed form here: the field gives up its width to the icon when the per-screen control needs the room.

Sidebar

262px fixed, never collapsible. Projects sit flat with a colour dot, active first; archived ones stay in the list at 45% rather than hiding, so a project never silently disappears.

Header

Title block, then at most one per-screen control, then search, then New issue. Screens with nothing to control leave the middle empty — Home drops the header entirely.

Role

The shell hides only what a role has no screen for. Actions a role cannot take render disabled with a reason on the screen itself, never quietly removed from the chrome.
